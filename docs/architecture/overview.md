# Architecture Overview

This project is a reusable CMS starter with a React frontend, Express API, Drizzle schema, PostgreSQL storage, and cookie/JWT authentication.

## Retained Areas

- Auth, setup, profile, forgot/reset password, login, and logout.
- Admin Dashboard, Content, Design, and System sections.
- CMS pages, revisions, media, sections, forms, submissions, menus, sidebars, SEO, redirects, docs, settings, activity logs, and backups.
- Generic public CMS rendering, sitemap, robots, branding, and media/uploads with S3-compatible object storage support.

## Removed Areas

Domain features such as directory, therapist portal, events, CRM, subscriptions, applications, references, recordings, specializations, guest registration, contact-professional flows, and blog are intentionally absent.
