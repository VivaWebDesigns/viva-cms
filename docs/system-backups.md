# System Backups

The retained backup system is intended for CMS data and media metadata.

Backups cover users, settings, docs, CMS pages, revisions, media, sections, menus, sidebars, forms, submissions, SEO settings, redirects, editor locks, activity logs, and backup metadata required by the implementation.

Use the System backups admin page or the provided backup scripts after configuring database access and S3-compatible object storage, such as Railway Buckets or Cloudflare R2.
